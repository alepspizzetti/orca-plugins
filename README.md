# Plugins do Orca

Marketplace pessoal para plugins do [Orca](https://www.onorca.dev/).

O arquivo `orca-marketplace.json` lista os plugins. Cada plugin publicado terá seu próprio repositório Git com um `orca-plugin.json` na raiz.

Para usar este marketplace, publique este repositório em um servidor Git e adicione a URL em **Settings → Plugins → Marketplaces** no Orca. O sistema de plugins precisa estar habilitado em **Settings → Plugins**.
